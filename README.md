# 崎駒線（さきこません） 運行記録アプリ

`sakiba-line_requirements.txt`（版 0.2）に沿ったPWA。ビルド不要の素のHTML/JS（ESモジュール）で、データは端末内の IndexedDB にだけ保存する。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` / `css/app.css` | 画面と意匠（黒地にアンバー・緑、白地テーマあり） |
| `js/engine.js` | 判定エンジン（通過・補間・推定・停車・到着）。生の測位だけから結果が決まる |
| `js/app.js` | 各画面（運転台・記録・台帳・ダイヤ・分析・データ） |
| `js/locator.js` | Geolocation（watchPosition, 高精度）と模擬走行 |
| `js/analysis.js` | ダイヤ作成、信号周期の推定、ダイヤグラム、軌跡からの距離 |
| `js/exporter.js` | CSV（passages / stops / track）、台帳JSON、バックアップ |
| `js/db.js` | IndexedDB |
| `sw.js` / `manifest.webmanifest` | オフライン動作とホーム画面への追加 |
| `tests/engine.test.html` | 判定エンジンの試験（ブラウザで開く） |
| `sample-stations.json` | 試用の台帳（**座標とキロ程はすべて仮**） |

## 動かし方

PC で確認する場合:

```bash
python -m http.server 8765
```

`http://localhost:8765/` を開く。`http://localhost:8765/?sim=10` で模擬走行（10倍速）。

### Android で使う

Geolocation と Service Worker は HTTPS が必要。たとえば GitHub Pages など静的ホスティングに
このフォルダを置き、Android の Chrome で開いて「ホーム画面に追加」する。
一度開けば以後はオフラインで動く。ファイルを更新したら `sw.js` の `VERSION` を上げる。

## 台帳JSONの形式

```json
{
  "stations": [
    { "id": "S01", "name": "自宅", "type": "yard", "lat": 35.0, "lon": 139.0, "km": 0, "kmSource": "gsi" },
    { "id": "S02", "name": "大崎警察署前", "type": "signal", "lat": 35.0, "lon": 139.0, "segKm": 0.290, "kmSource": "gsi", "note": "左折" },
    { "id": "S06", "name": "大橋一丁目", "type": "signal", "ixNo": "5339351775", "lat": 35.0, "lon": 139.0, "segKm": 1.115, "kmSource": "binran", "r": 50 }
  ]
}
```

- 並び順がそのまま台帳の順（キロ程順）になる。
- `type`: `yard`（停車場）/ `signal`（信号駅）/ `marker`（標識）
- キロ程は `km`（通算）か `segKm`（前の駅からの区間距離）のどちらか。便覧の地点間距離は `segKm` で入れればよい。
- `kmSource`: `binran` / `gsi` / `gps` / `other`
- `r` は判定円の半径（m）。省略すると設定の既定値（40 m）。

## 仕様書からの解釈・補足

- **終点の通過時刻**：終点で停車しているあいだの最接近点には意味がないため、終点の通過時刻は到着時刻とした。
- **起点での待機**：運転開始から起点の判定円を出るまでの停車は記録しない（乗車前の立ち止まり）。
- **境界の揺らぎ**：判定円を出たとみなすのは半径＋10 m を超えたとき。出てから30秒以内に同じ駅へ戻った場合は1回の通過として扱う（どちらも設定で変更可）。
- **発車の確定**：低速でない測位が2回続いたら発車とし、その1回目の時刻を発車時刻とする（GPSの揺らぎで停車が細切れになるのを防ぐ）。
- **停車中の走行距離**：残り距離の計算では、低速の測位間の移動を走行距離に積まない。
- **起点を伏せた書き出し**：台帳の起点座標を空にし、track.csv からは起点の周囲（既定300 m）の測位を除く。
- **必要時速 → 区間の目安速度**（試走後の変更）：要件 4.6 の「定時に通過するのに必要な平均時速」は、いつも止まらない信号で一度止まるとすぐ「回復不能」になり、無理な回復をあおるため廃止した。代わりに、過去の運転から区間ごとの目安速度を出し、時速計の緑の印で示す（数字は出さない）。次が信号の区間は止まらずに通過できたときの走行速度の中央値、一度も通過できていない信号の手前は遅めの値（下位25%）。上限は設定の 40 km/h。
- **着予想**：最後に通過した駅の時刻に、過去の運転での「その駅から到着までの時間」の中央値を足し、今の区間がいつもより遅れていればその分を足す。さらに信号1つ分（信号停車の中央値、20〜90秒）の余裕を加える。
- **定時差**：走行中の重要度は低いので、経過・現在時刻と同じ大きさの1行に縮めた（ダイヤがあるときだけ表示）。
- **信号周期の推定**：模擬走行の記録は使わない。
- **再計算**：運転の詳細画面から、保存済みの軌跡を今の台帳と設定で判定し直せる（座標や半径を直した後に使う）。
